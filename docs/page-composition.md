# Planned page composition

This document maps the supplied references to future reusable building blocks. It is a planning contract, not a UI implementation.

## Shared site shell

- Announcement or utility strip, if required
- Header and primary navigation
- Main content container
- Footer with navigation, contact details, newsletter form, and legal links

## Home

- Campaign hero
- Leadership model/map section
- Value or program card grid
- Partner logo cloud
- Regional presence map
- Organization overview
- FAQ accordion
- Final call to action

## About

- About hero
- Leadership model overview
- Partner logo cloud
- Systems/process explanation
- Program showcase
- Team or community media section
- Organization FAQ
- Final call to action

## Contact

- Contact hero
- Contact details
- Contact form
- Optional office/location information
- Frequently asked questions

## Program detail

- Program hero and primary action
- Program overview
- Key metrics or benefits
- Certification/process explanation
- Curriculum or module outline
- Pricing/funding callout
- Testimonials
- FAQ
- Related programs

## Insight detail

- Article header and metadata
- Rich content body
- Optional table of contents
- Inline call to action
- Author information
- Related insights

## Reuse rule

Visual similarity alone does not make a component reusable. Put configurable cross-page patterns in `components/sections`; keep content-specific orchestration inside the owning feature.
